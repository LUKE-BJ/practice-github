사업별 근거 표 에이전트 (첫 버전)

경영평가 준비에서 사업의 추진배경·방향을 정부 정책 자료와 연결할 때, 근거를 찾아 표로 정리하는 일을 에이전트(Claude Code skill)에게 맡겨 본 실습입니다. 저장소: LUKE-BJ/practice-github

목적

  • 풀려는 문제: 근거 자료를 여러 창을 열어 찾고 표로 옮겨 쓰느라 경영평가 준비에 2~3일(16~24시간)이 걸립니다.
  • 이 버전이 하는 일: 사업안내 PDF를 읽어 사업별로 나누고, 현 정부(2025-06 이후)의 정부 자료·국무회의 자료에서 근거를 찾아 출처가 붙은 사업별 근거 표를 만듭니다.
  • 하지 않는 일: 추진배경·방향 문장 작성, 평가 양식 기입, 서버·앱 설치·외부 계정 연동.

사용법

Claude Code에서 이 폴더를 열고 사업 자료를 raw/에 둔 뒤 "근거 표 만들어줘"처럼 맡기면 evidence-table skill이 아래 순서로 처리합니다.

  1. 읽기 — powershell out\도구\읽기.ps1 (PDF는 pdftotext)
  2. 사업별 나누기 — powershell out\도구\나누기.ps1 -From 1 -To N
  3. 근거 찾기 — 국무회의는 node out\도구\근거검색_국무회의.js, 정부 자료는 정책브리핑(korea.kr) 등에서 쪽을 직접 열어 확인한 것만 표만들기.js에 손으로 적음
  4. 표 만들기 — node out\도구\표만들기.js out → out/{사업명}_근거.md
  5. 점검 — powershell -File out\도구\판정금지검사.ps1

필요한 것: PowerShell, Node.js, pdftotext, 국무회의 검색용 korea-cabinet-stp skill의 로컬 데이터(bundle.json, 이 저장소에 없음). 원자료 raw/는 저장소에 올리지 않습니다.

한계

  • 사업은 모두 161건인데 10건만 돌렸습니다. 시간은 10건 기준이며, 대부분 외부 사이트에서 근거를 찾고 확인하는 데 쓰였고 사업이 늘수록 길어집니다.
  • 표만들기.js의 EV·MAP은 확인한 근거를 손으로 적는 방식이라 사업이 늘면 병목입니다.
  • 첫 실행의 사업 4·7번은 찾은 근거가 없어 행이 없고, 6·9·10번은 반도체 일반 근거만 있어 "간접"으로 표시했습니다.
  • 정부 자료 인용은 도구가 뽑은 것이라 원문과 눈 대조가 필요합니다. 본문을 열지 못한 보도자료는 제목만 적었습니다.
  • 국정과제 발표 내용은 언론 보도이고 국정과제 원문은 열지 못했습니다. 국무회의 안건의 "결과" 칸은 값이 없습니다.
  • 두 번째 실행의 10건은 원문 글자 수 순으로 골랐습니다. 내용의 질을 재는 값이 아닙니다.
  • 사업안내 PDF의 쪽 머리말은 2025년인데 파일 이름은 2026입니다. 어느 해 안내인지 확인하지 못했습니다.
  • 기준선(근거 표까지 걸린 시간)과 일치 판정의 허용 건수는 아직 정해지지 않아 비교하지 않았습니다. 사업자료와 정부 문서의 일치는 담당자가 4_대조용.md로 눈으로 대조해야 합니다.
  • 이 저장소는 Public이고 out/중간기록/에 사업안내 PDF의 추출 원문이 들어 있습니다. 공개해도 되는 자료인지는 확인하지 못했습니다.
