# 사업별 근거 표 에이전트 (첫 버전)

사업 자료를 받아 사업마다 "근거 · 출처" 표를 만든다. 한 번에 이어서 처리하고 단계마다 중간기록을 남긴다. 기획안: `02_기획안(수정).md`.

## 지킬 조건

- 결과물은 `out/` 안에만 만든다. 이 파일(SKILL.md)만 예외다.
- `raw/` 원본은 읽기만 한다. 고치거나 지우거나 이름을 바꾸지 않는다.
- 서버, 설치, 외부 계정 연동은 쓰지 않는다. 설치가 필요한 skill·agent는 쓰지 않는다.
- 사업 자료의 문장을 외부로 보내지 않는다. 검색어에는 일반 주제어만 쓴다.
- 출처가 없는 근거는 표에 넣지 않는다. 찾은 근거가 없으면 비워 두고 지어내지 않는다.
- 현 정부(2025-06 이후)의 자료만 근거로 쓴다. 이전 정부 자료는 제외하고 3_근거찾기.md에 이유를 적는다.
- 추진배경·방향 문장을 쓰거나 평가 양식에 옮겨 쓰지 않는다.
- 정해지지 않은 것(정리 항목, 표의 그 밖의 열 등)은 〔확인필요〕로 남긴다.

## 순서 (중간에 멈추지 않고 이어서)

시작 시각을 `out/중간기록/0_실행기록.md`에 먼저 적고, 실행 전 `raw/` 해시와 파일 목록을 `out/중간기록/_snapshot_before.txt`에 남긴다.

1. **읽기** — `powershell out\도구\읽기.ps1`. PDF는 `pdftotext`, .hwpx·.docx는 압축 안 XML로 읽는다. 구형 .hwp는 "읽기 불가"로 기록한다. → `1_읽기결과.md`, `1_원문_*.txt`
2. **사업별 나누기** — `powershell out\도구\나누기.ps1 -From 1 -To N`. 목차의 사업 번호로 나누고 원문을 그대로 싣는다. → `2_사업정리.md`
3. **근거 찾기**
   - 국무회의: `node out\도구\근거검색_국무회의.js <korea-cabinet-stp의 site/data/bundle.json> out\중간기록\3_근거찾기_국무회의.md 2025-06-01` (로컬 읽기 전용)
   - 정부 자료: 정책브리핑(korea.kr) 등 외부 사이트에서 찾고, 쪽을 직접 열어 날짜·제목·발표 기관·인용을 확인한다.
   - 확인한 것만 `out\도구\표만들기.js`의 `EV`(근거)와 `MAP`(사업↔근거)에 적는다. → `3_근거찾기.md`
4. **표 만들기** — `node out\도구\표만들기.js out`. → `out/{사업명}_근거.md`(사업마다 하나), `중간기록/4_대조용.md`
5. **검증·점검** — 아래 기준으로 확인하고 `4_검증.md`, `5_조건점검.md`에 적는다.

## 합격 조건

| 항목 | 조건 |
|---|---|
| 소요 시간 | 한 번 돌리는 데 30분 이내 |
| 출처 | 표에서 출처 칸이 빈 행 0건 |
| 형식 변환 | 변환 때문에 내용을 새 파일에 다시 만든 횟수 0회 |
| 사업자료와 정부 문서의 일치 | 담당자가 `4_대조용.md`로 눈으로 대조. 허용 건수 〔확인필요〕 |
| 근거 모으기 | 사업 1건당 열어 볼 파일 1개 |

## 알려진 한계

- `표만들기.js`의 `EV`/`MAP`은 사람이 확인한 근거를 손으로 적는 방식이다. 사업 수가 늘면 이 단계가 병목이다.
- 사업↔근거 연결은 "제안"이며 담당자가 눈으로 판정한다.
- 정부 자료 인용은 페이지를 읽는 도구가 뽑은 것이라 원문과 눈 대조가 필요하다.
