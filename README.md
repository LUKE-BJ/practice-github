# 사업별 근거 표 에이전트 (첫 버전)

경영평가 준비에서 사업의 추진배경·방향을 정부 정책 자료와 연결할 때, 근거를 찾아 표로 정리하는 일을 에이전트(Claude Code skill)에게 맡겨 본 실습 저장소입니다.

## 목적

- 풀려는 문제: 근거 자료를 여러 창을 열어 찾고 표로 옮겨 쓰느라 경영평가 준비에 2~3일(16~24시간)이 걸립니다. (`01_페인포인트.md`)
- 이 버전이 하는 일: 사업 자료(사업안내 PDF)를 읽어 사업별로 나누고, 현 정부(2025-06 이후)의 정부 자료·국무회의 자료에서 근거를 찾아 출처가 붙은 사업별 근거 표를 만듭니다.
- 하지 않는 일: 추진배경·방향 문장 작성, 평가 양식 기입, 서버·앱 설치·외부 계정 연동. (`02_기획안.md`, `.claude/skills/evidence-table/SKILL.md`)

## 구성

| 위치 | 내용 |
|---|---|
| `01_페인포인트.md` | 문제, 요구, 현재 성능, 검증기준, 기준선 |
| `02_기획안.md` | 형태(에이전트), 범위, 입력·처리·산출물, 검증 방법 |
| `.claude/skills/evidence-table/SKILL.md` | 에이전트 정의: 지킬 조건과 5단계 순서 |
| `out/도구/` | `읽기.ps1`, `나누기.ps1`, `근거검색_국무회의.js`, `표만들기.js`, `판정금지검사.ps1` |
| `out/2026-10-23/` | 두 번째 실행 결과: 근거 표 10개와 `중간기록/` |
| `out/` (바로 아래) | 첫 실행 결과: 근거 표 10개와 `중간기록/` |
| `5주차_기록.md`, `기록.md` | 수업 기록 |

`raw/`(원자료)는 `.gitignore`로 제외되어 저장소에 없습니다.

## 사용법

Claude Code에서 이 폴더를 열고 사업 자료를 `raw/`에 둔 뒤 "근거 표 만들어줘"처럼 맡기면 `evidence-table` skill이 아래 순서로 처리합니다. 손으로 단계를 실행할 때의 명령은 SKILL.md에 적힌 그대로입니다.

1. 읽기 — `powershell out\도구\읽기.ps1` (PDF는 `pdftotext`로 읽음)
2. 사업별 나누기 — `powershell out\도구\나누기.ps1 -From 1 -To N`
3. 근거 찾기 — 국무회의는 `node out\도구\근거검색_국무회의.js <bundle.json> <출력.md> 2025-06-01`, 정부 자료는 정책브리핑(korea.kr) 등에서 쪽을 직접 열어 확인한 것만 `표만들기.js`의 `EV`·`MAP`에 손으로 적음
4. 표 만들기 — `node out\도구\표만들기.js out` → `out/{사업명}_근거.md`
5. 점검 — `powershell -File out\도구\판정금지검사.ps1` (결과 파일에 판정 문구가 없는지 확인)

필요한 것: PowerShell, Node.js, `pdftotext`, 그리고 3단계의 국무회의 검색에 쓰는 `korea-cabinet-stp` skill의 로컬 데이터(`bundle.json`). `bundle.json`은 이 저장소에 없습니다.

측정값만 적습니다. 기준을 넘었는지 판단하는 '판정' 칸은 비워 두었고 담당자가 채웁니다.

- 첫 실행의 근거 행 수 20행과 형식 변환 0회는 `out/중간기록/4_검증.md`에서 가져왔고, 이번에 다시 세지는 않았습니다.
- `판정금지검사.ps1`을 이번에 실행한 결과, 검사한 파일 31개에서 위반이 없었고 종료 코드는 0이었습니다.

## 한계

- 사업 수: 사업은 모두 161건인데 두 번 모두 10건만 돌렸습니다. 시간은 10건 기준이라 전체를 돌릴 때의 시간을 알려 주지 않습니다. 시간의 대부분은 외부 사이트에서 근거를 찾고 확인하는 데 쓰였고 사업이 늘수록 길어집니다.
- 수작업 단계: `표만들기.js`의 `EV`·`MAP`은 사람이 확인한 근거를 손으로 적는 방식이라 사업이 늘면 병목입니다.
- 근거 없는 사업: 첫 실행의 사업 4·7번은 찾은 근거가 없어 표에 행이 없습니다.
- 간접 근거: 첫 실행에서 사업 6·9·10번은 반도체 일반 근거만 있어 "간접"으로 표시했습니다.
- 인용 확인: 정부 자료 인용은 페이지를 읽는 도구가 뽑은 것이라 원문과 눈 대조가 필요합니다. 본문을 열지 못한 보도자료는 제목만 적었습니다.
- 원문 미확인: 국정과제 발표 내용(E4)은 언론 보도이고 국정과제 원문은 열지 못했습니다. 국무회의 안건의 "결과" 칸은 아카이브에 값이 없습니다.
- 선정 기준: 두 번째 실행의 10건은 원문 글자 수 순으로 골랐습니다. 표·그림 설명이 많은 사업이 유리하고 내용의 질을 재는 값이 아닙니다.
- 연도 불일치: 사업안내 PDF의 쪽 머리말은 2025년인데 파일 이름은 2026입니다. 어느 해 안내인지 확인하지 못했습니다.
- 미측정: 기준선인 "근거 표까지 걸린 시간"과 사업자료·정부 문서 대조의 허용 건수는 아직 정해지지 않아(〔확인필요〕) 비교하지 않았습니다. 사업자료와 정부 문서의 일치 여부는 담당자가 `4_대조용.md`로 눈으로 대조해야 합니다.
- 공개 범위: 이 저장소는 Public이고 `out/중간기록/`에 사업안내 PDF의 추출 원문(`1_원문_*.txt`)이 들어 있습니다. 공개해도 되는 자료인지는 이 README로 확인하지 못했습니다.
